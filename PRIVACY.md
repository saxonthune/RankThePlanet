# RankThePlanet Privacy Policy

Effective August 25, 2026.

RankThePlanet stores Collections, Locations, Reviews, provider configuration, and API keys on the user's device. RankThePlanet does not include advertising or analytics SDKs and does not sell personal information.

The app contacts these services to provide features the user requests:

- OpenFreeMap supplies map tiles and receives ordinary network request data such as an IP address.
- The active Location Provider receives search text or map coordinates when the user searches for a place or resolves a dropped pin. The built-in provider uses Photon. A user may configure another provider, including Google Places, and that provider's policy governs its processing.
- When a user exports or shares a Collection, the user chooses the destination and the receiving app or service governs the exported file.

RankThePlanet does not request background location access. Deleting the app removes its private on-device data, subject to operating-system backup behavior. Android backup is disabled for the app.

For questions, support, or deletion help, open an issue at <https://github.com/saxonthune/RankThePlanet/issues>.
